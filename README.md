# QuantPyToolkit

**QuantPyToolkit** is a starter Python SDK for quantitative finance analytics — designed to be a foundation for building data utilities, financial metrics, and simple backtesting capabilities. It aims to demonstrate clean Python design, modular code, and quant-focused functionality suitable for expansion into a production-ready tool.

---

##  Overview

QuantPyToolkit helps users:

- Fetch and handle financial time series data (dummy data included for now).
- Compute basic financial metrics like daily returns and annualized volatility.
- Build a foundation for more advanced quant tools such as portfolio analytics and backtesting.
